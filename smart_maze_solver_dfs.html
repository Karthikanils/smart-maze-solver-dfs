Smart Maze Solver Using Depth-First Search (DFS)

Data Structures & Algorithms Implementation Report

1. Problem Statement & Context

Autonomous navigation in grid-based environments is a foundational challenge in computer science, robotics, gaming AI, and network routing. The goal of a maze solver is to systematically explore a two-dimensional grid from a designated Start node to an End goal while avoiding impassable obstacles (walls).

This application demonstrates how Depth-First Search (DFS) explores complex graph structures using a systematic backtracking strategy. Through real-time execution controls, call-stack visualization, and performance analytics, this tool illustrates memory usage, state exploration, and algorithmic constraints.

2. Algorithm Explanation: Depth-First Search (DFS)

Depth-First Search is an unweighted graph traversal algorithm that follows a single pathway as deep as possible before backtracking. It operates strictly on a Last-In, First-Out (LIFO) stack dynamic, implemented either iteratively via an explicit stack data structure or recursively via the system call stack.

Operational Steps

  1. Push the Start node onto the Stack and mark it as visited.
  2. While the stack is not empty:
    • Peek/Pop current node u from the stack top.
    • If u is the End goal, reconstruct the solution path and terminate.
    • Otherwise, select an unvisited valid neighbor v (Up, Right, Down, Left).
    • Mark v as visited, record parent mapping, and push v onto stack.
    • If no unvisited neighbors exist, backtrack by popping the node.

Core Backtracking Principle

When DFS encounters a dead end (a node with no unvisited adjacent passages), it unwinds the stack until it encounters a previous node with unexplored branches. This exhaustive search guarantees that if a continuous path exists from Start to End, DFS will discover it.

3. Time & Space Complexity Analysis

Time Complexity: O(V + E)

In a grid graph with R rows and C columns:

  • Vertices (V): Total grid cells = R × C.
  • Edges (E): Maximum 4 cardinal connections per cell = E ≤ 4V.

Since each cell and edge is processed a constant number of times (checked at most 4 times for boundaries/walls), the overall time complexity scales linearly with the total grid size: O(R × C).

Space Complexity: O(V)

Auxiliary space used by the algorithm consists of:

  • Visited Matrix: Boolean grid storing visitation state = O(R × C).
  • Call / Explicit Stack: In the worst case (a long narrow winding path with no branches), the stack depth can reach O(R × C).

Total auxiliary memory bound is strictly O(R × C).

Key Limitation: Non-Optimal Path Length

Unlike Breadth-First Search (BFS) or A* Search, DFS does NOT guarantee the shortest path in unweighted graphs. Because DFS commits greedily to a single direction until blocked, it may traverse an unnecessarily long, convoluted route to reach a destination adjacent to the start.
